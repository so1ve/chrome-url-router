# Privacy Policy

Last updated: August 20, 2026

Chrome URL Router handles URLs locally in order to open them in the last
focused normal Chrome window.

## Data handled

The extension receives a URL that the user has asked the operating system to
open. A URL may be considered web browsing activity under Chrome Web Store
policy.

## How data is used

The URL is used only to create a tab in the user's last focused normal Chrome
window. It is passed between the locally installed Chrome URL Router native
host and the extension through Chrome Native Messaging.

## Storage, sharing, and retention

URLs are not sent to the developer or any third party. Chrome URL Router does
not store or log URLs, use analytics or advertising, or sell or share user
data. A URL is retained in memory only for the time needed to open its tab and
return the result to the local native host.

## Permissions

The `nativeMessaging` permission is used only to communicate with the locally
installed Chrome URL Router native host. The extension does not download or
execute remote code.

## Limited Use

The use of information received from Google APIs will adhere to the Chrome Web
Store User Data Policy, including the Limited Use requirements.

## User control

Users can stop all data handling by uninstalling the extension and the Chrome
URL Router native host.
